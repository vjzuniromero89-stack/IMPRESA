# IMPRESA v3.40

- Ventas ahora usa el mismo resumen circular visual de Gastos/Inventario.
- Nueva pestaña **Control de dinero**.
- Calcula dinero real = suma de Banco y Efectivo en C$ + equivalente US$.
- Calcula flujo esperado = saldo inicial + ventas cobradas - gastos pagados.
- Compara dinero esperado contra dinero real y muestra la diferencia.
- Transferencias internas no se cuentan como ingreso/gasto.
- Inventario no entra en Control de dinero.
- Historial mensual de entradas y salidas.
- El saldo inicial puede ajustarse y queda guardado por mes en el navegador; si existe un cierre anterior, se propone el Banco y Efectivo de ese cierre.
