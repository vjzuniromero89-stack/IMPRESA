# IMPRESA v3.56.7

- Control de dinero: Tipo detecta automáticamente Saldo inicial, Entrada, Salida o Transferencia.
- Se reemplazan las columnas separadas Entrada/Salida por una sola columna Monto.
- Monto verde para entradas, rojo para salidas y signo + / −.
- Movimientos Generales usa la misma lógica: Fecha, Descripción, Tipo, Monto, Saldo final.
- No cambia la lógica contable ni requiere migración de Supabase.
