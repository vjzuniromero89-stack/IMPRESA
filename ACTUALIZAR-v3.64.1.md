# IMPRESA v3.64.1

Base: v3.64 (no usa v3.65 ni v3.66).

Cambios en Ventas:
- Descripción queda como campo libre sin mensaje interno.
- Categoría ahora es una lista con flecha: Producto / Servicio.
- Se eliminan Cantidad y Precio.
- Solo queda Total C$, que se escribe manualmente.
- Cada línea de venta ya no se vincula a un producto de inventario.
- Contabilidad y Control de dinero conservan la misma lógica de v3.64.

No requiere migración nueva de Supabase.
